#Design Decisions

## LED Coloring

Having pairs of colors seemed easier to differentiate between than cycling between them. It also happened to be beneficial when I added more input buttons, so the different buttons were 'assigned' to different colors.

## LED spacing

Leaving an empty row between each LED is just enough space to have them side-by-side. 

## Pin spacing

Leaving empty rows to match the LED spacing is both more aesthetically pleasing and easier to physically manipulate.

## Button layout

The second button in each row is offset so that it is easier to press individually. I thought about offsetting the 4th button as well, but they have different functionality, so I decided to just move them further out. The furthest button spacing is where the long jumper cable could lie flat.

## Resistor leads

I considered trimming the resistor leads, but I left them at full length in case I wanted to reuse them for something else.

## Jumper cable layout

Some of the jumper cables (like the ones going to ground from the buttons) are angled due to jumper cable lengths. When possible, I try to use the same color/length cable for the same purpose.
